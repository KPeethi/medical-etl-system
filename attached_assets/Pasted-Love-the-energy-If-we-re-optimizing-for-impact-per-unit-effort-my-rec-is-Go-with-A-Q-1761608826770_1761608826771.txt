# A) Quick Wins (production guardrails)

### 1) Config validation at ingress (JSON Schema + hard fail)

* **Behavior:** If `identity.roster.path` is missing/empty/unreadable → HTTP 400 with human message.
* **Minimal schema (drop-in):**

```json
{
  "type": "object",
  "properties": {
    "identity": {
      "type": "object",
      "properties": {
        "roster": {
          "type": "object",
          "properties": {
            "path": {"type": "string", "minLength": 1}
          },
          "required": ["path"]
        }
      },
      "required": ["roster"]
    }
  },
  "required": ["identity"]
}
```

* **Error string (clear, actionable):**
  `ERROR: identity.roster.path is required and must point to a readable file. Tip: include it in the request body or supply a Practice Pack.`

### 2) Better diagnostics (no more “quiet 12 unmapped”)

* **On run start:** log a “preflight summary” (src count, ext whitelist, roster rows, detected columns).
* **On >60% unmapped in dry-run:** return **HTTP 409** with:
  `High unmapped rate (83%). Likely bad roster mapping. Run /api/unmapped to preview examples.`

### 3) Roster autodetect (header mapper with confidence)

* **Heuristics:** map candidate columns by regex + frequency + value shape.

  * last: `(?i)\b(last|surname|l\s*name)\b`
  * first: `(?i)\b(first|given|f\s*name)\b`
  * dob: ISO / US dates; reject 01-01-1900, out-of-range years.
* **API:** `GET /api/identity/preview?roster=...` → returns:

```json
{
  "detected": {"last":"Last Name","first":"First Name","dob":"DOB"},
  "confidence": {"last":0.97,"first":0.96,"dob":0.92},
  "sample":[{"last":"Smith","first":"John","dob":"1980-05-15"}]
}
```

* **If user provides columns:** we trust them; autodetect is fallback only.

### 4) Practice Pack template generator (scaffold, optional)

* CLI: `python tools/make_practice_pack.py --name "Alexander OBGYN" --out C:\packs\Alexander`
* Output:

```
Alexander/
  patients.xlsx
  config.yml
  samples/
  README.txt
```

* **Postman body** can accept `practice_pack` OR explicit fields; explicit wins.
