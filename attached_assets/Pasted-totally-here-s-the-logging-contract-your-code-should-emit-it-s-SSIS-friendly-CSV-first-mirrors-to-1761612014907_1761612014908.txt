# Column cheat-sheet (what each means)

* **run_id**: UUID for the whole run/plan (ties all events together).
* **run_started_utc / event_time_utc / event_date / event_time**: timestamps; split fields simplify SSIS.
* **invoked_by_user / invoked_from_host**: `getpass.getuser()` + hostname.
* **host_platform / host_release / python_version**: environment fingerprint.
* **cwd / cmdline**: where/how the process was launched.
* **mode**: `dry_run` or `real`.
* **script_version**: your router version string.
* **src_root / dst_root**: roots passed in config.
* **src_path / relative_path / dst_path**: original location, path relative to `src_root`, and final Gold path (empty if skipped).
* **nested_level**: depth found during enumeration (0 at root).
* **action**: decision taken — see “Action values” below.
* **reason**: human explanation for odd cases (e.g., `unmapped_no_roster_match`, `bad_dob`); blank if normal.
* **dedupe_rule**: which rule fired (`hash`, `name_size_module`, `size_module`, `new`).
* **patient_key / last / first / dob**: canonical identifiers (dob ISO `YYYY-MM-DD`).
* **module**: `Labs | Imaging | Notes | Reports | General`.
* **file_ext**: lower-cased extension.
* **file_size_bytes**: integer size at source.
* **sha256**: content hash (always present if computed; blank if gated by `max_bytes`).
* **include_exts / exclude_exts**: echoes config (serialized JSON arrays).
* **max_bytes**: optional limit used during hashing/copy.

# Action values you’ll see

* **COPY_NEW** — first time this content/name; copied to Gold.
* **DUP_HASH** — exact duplicate by SHA256; skipped.
* **DUP_NAME_SIZE_MODULE** — same name+size in same module; skipped.
* **COPY_DUP_SIZE_MODULE** — same size+module but different name; copied to `_duplicate/<MODULE>/...`.
* **UNMAPPED** — no roster match (see **reason** for why).
* **ERROR** — unrecoverable issue (I/O, parse, etc.); **reason** describes it.

# Tiny code sketch (how to write the CSV row)

```python
def emit_log_row(ctx, item, action, dedupe_rule, reason=""):
    row = {
      "run_id": ctx.run_id,
      "run_started_utc": ctx.run_started_utc.isoformat().replace("+00:00","Z"),
      "event_time_utc": dt.datetime.utcnow().isoformat().replace("+00:00","Z"),
      "event_date": dt.date.today().isoformat(),
      "event_time": dt.datetime.utcnow().strftime("%H:%M:%S"),
      "invoked_by_user": ctx.user,
      "invoked_from_host": ctx.host,
      "host_platform": platform.system(),
      "host_release": platform.release(),
      "python_version": platform.python_version(),
      "cwd": str(Path.cwd()),
      "cmdline": " ".join(sys.argv),
      "mode": ctx.mode,
      "script_version": ctx.version,
      "src_root": ctx.src_root,
      "dst_root": ctx.dst_root,
      "src_path": str(item.src),
      "relative_path": str(item.src).replace(ctx.src_root + os.sep, ""),
      "dst_path": str(item.dst) if item.dst else "",
      "nested_level": item.depth,
      "action": action,
      "reason": reason,
      "dedupe_rule": dedupe_rule,
      "patient_key": item.patient_key or "",
      "last": item.last or "",
      "first": item.first or "",
      "dob": item.dob or "",
      "module": item.module or "",
      "file_ext": item.src.suffix.lower(),
      "file_size_bytes": item.size,
      "sha256": item.sha256 or "",
      "include_exts": json.dumps(ctx.include_exts),
      "exclude_exts": json.dumps(ctx.exclude_exts),
      "max_bytes": ctx.max_bytes or 0
    }
    csv_writer.writerow(row)
    db_buffer.append(row)
```
